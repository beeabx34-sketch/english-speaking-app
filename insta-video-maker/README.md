# ほいくショート — インスタ動画メーカー（プロトタイプ）

授業や行事の**写真・動画**と**説明文**を入れると、高校生向けのインスタ（リール）用
縦型動画（1080×1920・音声なし）をブラウザだけで生成するアプリです。

## 使い方

`index.html` をブラウザ（Chrome / Edge / Safari の最新版推奨）で開くだけで動きます。
サーバーもインストールも不要です。

1. **素材** — 写真・動画をまとめて追加。順番の入れ替え、表示秒数の調整ができます
2. **文章** — 説明文を入力して「自動生成」。タイトル（高校生向けフック）・各カットのコメント・締めの一言（CTA）が作られます。「別パターン」で何通りも切り替え可能。手で直すこともできます
   - **🤖 AI生成（オプション）**: Anthropic APIキーを入れると、AI（Claude）が各写真の内容を実際に見て、写真に合ったコメント・タイトル・ハッシュタグを生成します。写真は縮小版のみAPIに送信されます
3. **デコ** — テーマ（ポップ / ガーリー / シンプル / エモ）× 写真の動き × カット切り替えを選択。「おまかせガチャ」で全部ランダムに組み合わせ
4. **ぼかし** — 写ってはいけない人をクリックで指定してぼかし。ドラッグで移動、スライダーでサイズ変更
5. **書き出し** — プレビュー再生して MP4（環境により WEBM）でダウンロード。投稿用キャプション＋ハッシュタグもコピーできます

## プライバシー

写真・動画は**端末のブラウザ内だけで処理**され、外部サーバーには送信されません
（例外: AI生成機能を自分のAPIキーで使った場合のみ、縮小画像がAnthropicのAPIに送信されます）。

## パフォーマンス

読み込み時に、写真は動画書き出しに十分な解像度（長辺2200px）へ自動で軽量化されます。
iPhoneの高解像度写真でも複数枚を数秒で取り込めます。

## 既知の制限（プロトタイプ）

- 書き出しはリアルタイム録画のため、動画の長さと同じ時間がかかります
- ブラウザによっては WEBM 形式になり、投稿前に MP4 への変換が必要な場合があります
- 動画カット内で人が動く場合、ぼかしは追従しません（範囲を大きめに設定してください）
- コメント自動生成はパターン式です（AI 生成への差し替えは今後の拡張候補）
