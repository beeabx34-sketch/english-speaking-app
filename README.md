# 瞬間英作文トレーナー

日々の行動や気持ちをその場で英語にして声に出す「瞬間英作文」を練習するためのWebアプリ（PWA）です。話した英語を Claude API が即座に添削し、より自然な表現をお手本として読み上げます。iPhone + AirPods での利用を想定しています。

## 機能

- 🎤 **話す** — マイクボタンをタップして英語で話すと、Web Speech API がリアルタイムに文字起こし
- ✍️ **添削** — Claude（claude-sonnet-4-6）が文法チェック・修正・より自然な表現・日本語解説・レベルアップ表現を返す
- 🔊 **聞く** — 修正文と自然な表現を en-US 音声で自動読み上げ（速度 0.7x / 1.0x / 1.2x）
- 📚 **記録** — 練習履歴を端末内（localStorage）に保存。履歴タブから再生・削除が可能
- 💡 **日本語でヘルプ** — 単語や言い方が分からないときは「日本語でヘルプ」に切り替えて言いたいことを日本語で話すと、自然な英語表現と解説を返して読み上げてくれる
- 🙌 **ハンズフリーモード** — マイク常時オン。約2秒の沈黙で自動確定→添削→読み上げ→聞き取り再開をループ。読み上げ中は認識を自動停止し、"stop" と言えば終了。Wake Lock で画面消灯も防止
- 📴 **オフライン対応** — Service Worker により、オフラインでもアプリの起動と履歴の閲覧が可能（添削はオンライン時のみ）

APIキーと履歴はすべて端末内にのみ保存されます。サーバーは不要です。

## ファイル構成

```
index.html     … アプリ本体（HTML/CSS/JS すべて同梱・ビルド不要）
manifest.json  … PWAマニフェスト
sw.js          … Service Worker（オフラインキャッシュ）
icons/         … アプリアイコン
```

## 公開方法（iPhoneから使えるようにする）

### 方法A: GitHub Pages（このリポジトリをそのまま公開・おすすめ）

1. このブランチの内容を `main` ブランチに取り込みます（Pull Request を作成してマージ、または直接マージ）
2. GitHub でこのリポジトリを開き、**Settings → Pages** を開く
3. 「Build and deployment」の **Source** を「Deploy from a branch」にする
4. **Branch** で `main` / `/(root)` を選んで **Save**
5. 1〜2分待つと、次のURLで公開されます：

   ```
   https://beeabx34-sketch.github.io/english-speaking-app/
   ```

6. iPhoneのSafariでこのURLを開けば使えます

以後、`main` にpushするだけで自動的に更新されます。

### 方法B: Netlify Drop（アカウント不要・ドラッグ&ドロップだけ）

1. パソコンでこのリポジトリのファイル一式（`index.html`, `manifest.json`, `sw.js`, `icons/`）をひとつのフォルダに入れる
2. https://app.netlify.com/drop を開く
3. フォルダをブラウザにドラッグ&ドロップ
4. 数秒で `https://～.netlify.app` のURLが発行されるので、iPhoneのSafariで開く

※ Netlify Drop はログインしない場合、サイトが一定期間で失効します。継続利用するなら無料アカウントを作成してください。

> **注意:** マイク（音声認識）は HTTPS のページでしか動きません。GitHub Pages / Netlify はどちらも自動的に HTTPS になるので、そのままでOKです。

## ホーム画面への追加方法（iPhone）

1. **Safari** で公開したURLを開く（Chromeや他ブラウザではなくSafariで）
2. 画面下中央の **共有ボタン**（四角から上矢印が出ているアイコン）をタップ
3. メニューを下にスクロールして **「ホーム画面に追加」** をタップ
4. 名前（「瞬間英作文」）を確認して右上の **「追加」** をタップ
5. ホーム画面に追加されたアイコンから起動すると、アドレスバーのない全画面アプリとして使えます

## 初期設定

1. アプリを開き「設定」タブへ
2. **Anthropic APIキー**（`sk-ant-...`）を入力
   - キーは [Anthropic Console](https://console.anthropic.com/) で発行できます
   - キーはこの端末にのみ保存されます
3. 「練習」タブに戻り、マイクボタンをタップして英語で話す
4. 初回はマイクの使用許可を求められるので「許可」を選択

## 使い方のヒント

- **手動モード**: タップで録音開始 → 話す → もう一度タップで確定
- **ハンズフリーモード**: トグルをオンにすると、話して2秒黙るだけで自動添削。家事や散歩をしながらの練習に
- ハンズフリーを終わるときは、トグルをオフにするか **"stop"** と言うだけ
- AirPodsを接続していれば、そのままAirPodsのマイクとスピーカーが使われます
